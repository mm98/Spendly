# Brief 31 answers - a scan stays a draft

1. The rule. A scan is an order with status Draft from the upload until Create or Discard. "Save as draft" goes: leaving keeps the draft anyway, so the button would do nothing. Back, another page and closing the app keep the draft without asking, and leaving the review shows the toast "Kept in Drafts" with no Undo. The review footer stays Discard / Create. On the reading step, Cancel becomes Discard, since leaving the page now keeps the scan. Order create 3a notes, Actions inventory 16a.
2. Edits before leaving. Yes. What is on the screen is what is kept: changed values, ticked and unticked lines, and the marks, including which have been touched. Order create 3a notes.
3. Opening a draft later. The same review screen, 3a step 3, exactly as drawn: the amber bar with the count still to look at, the ticks, the tones, Jump to first. A value touched before leaving stays cleared. A draft still being read opens step 2. On a phone it is Check the reading (Mobile screens 7b). The file is not beside the form: it is in Attachments beneath the lines, as on a saved order, in the review too. Order create 3a step 3.
4. Finishing a draft. Create gives the status a scan gets today: the account's default, or the document's when Settings, Defaults allows it. The button stays "Create", the rule on every new record. Create says the draft becomes an order without a new word. Order create 3a notes.
5. Drafts card on Home. Named "Drafts". On desktop it is first in the left column, above Needs a look. On a phone it comes under This month, above Needs a look. Newest 3, "newest 3" beside the name, "All 5" in the head opening `/orders?status=Draft`. A row shows the file's picture, the vendor (the file name when no vendor was read), the file name and what is left to check ("2 values need a look", "4 lines", "Still reading", "Nothing read"), the scan day, and the total when one was read (the cell is empty when it was not). A row opens the draft in the review. The card is absent when there are no drafts. Home 10a, Mobile screens 7a.
6. Drafts elsewhere. Drafts leave Home's Recent orders. They stay in the order list with the grey pill, as today. The list is where every record is found by status, and drafts brought in by an import live there too. The Drafts card's All link is that list filtered to Draft. Order list 2b note, Home 10a notes.
7. Reading screen. Yes. Step 2: "Usually 5 - 10 seconds. If you leave, the scan is kept in Drafts on Home." Slow reading (6e): "You can leave this page. The scan is kept in Drafts on Home and the reading carries on."

## Decisions the build makes, applied

- A draft never removes itself, and its file is outside the 24-hour cleanup. Images and files 17a note.
- Discard uses the 6d dialog. Its body said the file stays in your uploads. It now reads "Discarding removes the reading and faktura-indbo-4471.pdf, and the draft leaves Drafts." States and confirmations 6d. 6e's Discard goes through the same dialog.
- The same file scanned again while its draft exists shows "Scanned before", with "Open that draft" as the first button. Order create 3c note.
- Without a reader key the blank scan is kept as a draft in the same way. Order create 3a notes.
