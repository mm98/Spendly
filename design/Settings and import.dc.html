IF "A WHOLE ORDER" IS PICKED INSTEAD
One row can't hold four item lines, so the item fields collapse. Quantity and unit price leave the list, item name becomes an optional description, and a required Order total appears — there is nothing to sum from. The grouping control disappears with them: every row is already its own order.
