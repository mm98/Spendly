NOTES FOR IMPLEMENTATION
This page exists to settle one question and is not a product screen. Nothing here changes the system: the family is set on each specimen's list wrapper only, and --font in tokens.css is still Poppins.
What to look at, in order. First, the two-line stack against the 42px mark: the white above the cap of the title comes from the family's ascender-to-cap gap, not from padding, so the row reads more evenly in a family where that gap is small. Second, the vendor name in row 2, which is the same string at the same column width in all four - where it truncates tells you how much the family costs in table width. Third, the amounts: all four carry tabular figures, so the columns stay aligned, but the figures differ in width and in how well they read at 11px.
If a family is adopted, the change is one token, but the consequences are not: column widths, truncation points, mark and control dimensions and the phone layouts were all set against Poppins' widths, and every page plus the handoff snapshots would need a pass.
